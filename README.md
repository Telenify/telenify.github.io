# telenify.github.io

Public website for Telenify, served by GitHub Pages at https://telenify.co.za.

Plain HTML + CSS, no build step. Font stored in `fonts/` (no Google calls), no cookies or tracking.

| File | Page |
|---|---|
| `index.html` | Home |
| `about.html` | About (mission) |
| `privacy.html` | Privacy Policy (POPIA) |
| `terms.html` | Website Terms |
| `styles.css` | All styles and brand colours |
| `CNAME` | Custom domain for GitHub Pages |

Rules: no personal information, no match footage, keep the "how" (leagues, prices, methods) private.
Preview locally: open `index.html` in a browser.
